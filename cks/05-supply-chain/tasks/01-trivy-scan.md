# Task 01 — Scan an image with Trivy

## Objective

Run Trivy against a public image and capture a summary.

## Requirements

1. Install Trivy locally (or use the official container image).
2. Scan `nginx:1.25` (or another image you deploy in lab).
3. Record count of HIGH/CRITICAL findings in your notes Gaps (do not paste full CVE dumps into the repo).

## Verify

Trivy exits and prints a vulnerability table; you noted HIGH/CRITICAL counts.
